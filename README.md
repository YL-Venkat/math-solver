# Math Solver

A web-based mathematical operations and problem-solving application.

## Features

- Arithmetic Operations
- Number Conversion
- Factorial
- Prime Number Check
- Modular Exponentiation
- Euler's Phi Function
- GCD & LCM
- Legendre Symbol
- User Authentication
- Google Sign-In
- User Profile

## Technologies

- HTML
- CSS
- JavaScript
- Supabase
- Google OAuth

## Deployment

The application is deployed using Vercel.
